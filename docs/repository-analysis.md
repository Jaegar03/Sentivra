# Repository Analysis — SENTIVRA

**Purpose of this document:** Before writing a single line of Sentivra's detection code, every repository named in the project brief was inspected (README, structure, license, maintenance signal). This is a *reference survey*, not a vendoring exercise — Sentivra's detectors are written from scratch, informed by the design patterns and pitfalls documented here. Nothing below was copy-pasted into the codebase.

**Method:** each repo was fetched directly from GitHub on 2026-09-24 and read for purpose, algorithm, dependencies, license, and maintenance signal. Where a repo did not exist, that is stated plainly instead of invented.

**Legend — Decision column:**
- `REFERENCE` — informs Sentivra's design, no code reused.
- `INTEGRATE (native binary)` — the real engine is optionally shelled out to / called via its own API, not reimplemented.
- `NOT FOUND` — URL given in the brief does not resolve; excluded from the analysis.
