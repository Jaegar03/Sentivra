# Datasets

The data itself is never committed. Everything here is either downloaded by `fetch_datasets.py` into `raw/` or generated by code, and both directories are gitignored. Reproducing any model starts from the scripts, not from files someone had lying around.

## Downloaded (`python research/datasets/fetch_datasets.py`)

The script writes `raw/MANIFEST.json` with the source URL, license, retrieval time and SHA-256 of every file.

| Dataset | License (verified 2026-09-24) | Used for | Status |
|---|---|---|---|
| [PhiUSIIL Phishing URL Dataset](https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+dataset) (UCI #967) | CC BY 4.0 | Phishing URL model | Downloaded; model not trained yet |
| [deepset/prompt-injections](https://huggingface.co/datasets/deepset/prompt-injections) | Apache-2.0 | Prompt-injection classifier | Downloaded; model not trained yet |
| [SecLists](https://github.com/danielmiessler/SecLists) `Fuzzing/Databases/SQLi/` | MIT | SQL injection evaluation (positives only) | Downloaded; model not trained yet |

Known properties that affect how each can be used are in [docs/model-card.md](../../docs/model-card.md#dataset-notes-for-models-not-yet-trained), notably PhiUSIIL's inverted labels and its homepage-only legitimate class.

## Generated

| Data | Code | Used for |
|---|---|---|
| Synthetic network flows | `backend/app/demo/network_flows.py` | Network models (v0.1.0) and the demo sample. Deterministic per seed; addresses from RFC 5737 documentation ranges; names under `.example` |

Synthetic data proves the pipeline works; it is not evidence of real-world performance. The model card says so next to every number derived from it.
